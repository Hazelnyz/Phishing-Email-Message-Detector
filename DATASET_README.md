# Dataset documentation — PhishGuard AI

## Provenance and generation

The generated training, validation, and generated test splits are synthetic.
`src/generate_dataset.py` combines authored template families with names, fake
domains, URL strings, phrasing changes, SMS spelling, casing changes, and
occasional typos. It uses seed 42. Re-running the script reproduces the split
assignments and generated text. The generator writes a `family` column so the
evaluation can keep complete message families together.

## Files and use

| File | Use |
|---|---|
| `data/train.csv` | Fits TF-IDF and candidate classifiers |
| `data/validation.csv` | Selects model and probability threshold |
| `data/standard_test.csv` | Message-level held-out evaluation from training families |
| `data/test.csv` | Template-family held-out evaluation; families are excluded from training and validation |
| `data/hard_test.csv` | Hand-written messages; never used for training, model selection, or threshold selection |
| `data/messages_full.csv` | Generated data inventory; not a training input |

Generated CSV files contain `message`, `label`, and `family`. The hand-written
hard test contains `message` and `label`. Split sizes are variable because
duplicate generated messages are discarded; the current counts are recorded in
`evaluation/metrics.json` and `docs/RESULTS_SUMMARY.md`.

## Template-family coverage

Phishing content includes account threats, credential and sensitive-data
requests, scholarship and payment lures, suspicious links, authority spoofing,
polite requests, and SMS-style wording. Legitimate content includes campus
notices, peer messages, routine services, urgent but ordinary notices, informal
requests, and link-bearing notices. Family holdout reduces direct template
reuse between training and family-held-out evaluation.

`hard_test.csv` contains manually authored legitimate urgent notices and links,
short informal requests, polite credential phishing, sensitive-information
requests, and sender-mismatch examples. Its messages are not generated by the
dataset script.

## Limitations

Labels in the generated set follow the authored templates and may not capture
real-world ambiguity. A family holdout cannot guarantee distributional
independence when families share vocabulary or scenario conventions. The hard
test is small and manually labeled; it cannot establish deployment performance.
See `docs/RESULTS_SUMMARY.md` for actual measured results and misclassifications.

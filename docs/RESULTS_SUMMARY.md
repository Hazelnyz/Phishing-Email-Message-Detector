# Evaluation results

Evaluation numbers are intentionally not copied into this document. The Flask
performance page reads the current values from [`evaluation/metrics.json`](../evaluation/metrics.json),
and the ordered console report is saved as [`evaluation/terminal_run.txt`](../evaluation/terminal_run.txt).
Run `python run_pipeline.py` to refresh both artifacts and the privacy-masked
misclassification file. Dataset sources and limitations are documented in
[`DATASET_CARD.md`](../DATASET_CARD.md).
